## 🛠️ CMS & Real-Time Administration

Clicking the **"CMS Mode"** toggle opens the Author Administration Drawer with tabbed controls:
- **Profile:** Live editing of author name, pen identity, descriptor, headline, working biography, quote, location, education, and languages.
- **Books & BOTM:** Select Book of the Month and configure catalogue metadata.
- **Philosophy:** Update the full-width philosophy section text.
- **Inboxes:** Review submitted contact form messages and newsletter signups, with one-click **Export to CSV**.
- **Data Version Control:** Export updated `content.json` for Git/Vercel deployment or reset to verified dossier defaults.
- All edits persist across sessions in browser `localStorage`.
